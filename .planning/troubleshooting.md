## 확인된 이슈
* 조치된 내용은 체크박스를 추가하여 마킹할 것. 대괄호 안에 확인 필요라고 되어있으면 기존에 조치했으나 여전히 문제가 있는 경우라고 사용자가 확인한 내용임.


## 기능 추가/개선
- [x] 프로그램 실행시 스플래시 스크린 추가    
    - 임베딩 모델 다운로드 및 로드하는 동안 스플래시 스크린 표시
    - 하단에 진행상태를 표시하는 프로그레스바를 추가. 특히 프로그레스바는 임베딩 모델 다운로드 상황을 반영할 수 있어야함.
    - 프로그레스바 위에는 현재 진행상황을 텍스트로 표시. (예: "임베딩 모델 다운로드 중...", "임베딩 모델 로드 중...")
    - 스플래시 스크린 우측 하단에는 버전 표시
    - 스플래시 스크린은 메인 화면이 로드되면 사라져야 함.

- [x] 시스템 트레이로 최소화 기능 추가
    - 프로그램 최초 실행 시 창 닫기 버튼을 누르면 대화상자를 표시하여 '종료' 또는 '최소화'를 선택할 수 있도록 함. 선택한 결과는 config로 저장하여 해당 설정이 계속 적용되도록 함.
    - 설정에 '최소화'로 되어있으면 창 닫기 버튼을 클릭하면 프로그램이 종료되지 않고 시스템 트레이로 최소화 되도록 함.
    - 설정에 '종료'로 되어있으면 창 닫기 버튼을 클릭하면 프로그램이 바로 종료됨.
    - 시스템 트레이로 최소화된 상태에서 트레이 아이콘을 우클릭 해서 프로그램을 종료할 수 있어야 함.

- [x] '파일 - 설정' 메뉴에 '환경 설정' 메뉴 탭 추가.
    - [x] '환경 설정' 탭에 '프로그램 종료 시 시스템 트레이로 최소화' 체크박스 추가.
    - [x] 체크박스 옆에 '설명' 텍스트 추가. (예: '체크 시 프로그램 종료 버튼을 클릭하면 프로그램이 종료되지 않고 시스템 트레이로 최소화 됩니다.')
    - [x] 체크박스 상태는 config에 저장하여 해당 설정이 계속 적용되도록 함.
    - [x] 향후 다른 설정들 추가가 용이하도록 미리 UI 레이아웃 구성

    




## 버그

- [x] 스플래시 스크린이 초기 인덱싱 권장 대화상자를 가림.
    - 초기 실행시 해당 대화상자는 가장 최상단에 뜨게 하여 스플래시 스크린이나 다른 창에 가려서 사용자가 인지하지 못하는 일이 없도록 해야함.
